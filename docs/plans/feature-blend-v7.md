# Ветка `feature/blend-v7` — финальный бленд под test: сегменты сущности, честный отбор, сиды моделей fallback (P1, @egrsid)

> Ветка от `main` (`dff0357` = сабмит v6, 23.56 — лучший). День сдачи 26.10: сабмиты до 18:00, осталось 2 попытки,
> проверка идёт ~3 ч 12 мин — обе отправки «вслепую». Поэтому v7 — только то, что выиграло на отложенных копиях;
> v8 — v7 + рискованное (окно агента короче, время — сидам членов бленда).

## 1. Зачем

- Разбор предложений holdhype (P3) по бленду — что верно, что нет (подробно — в разделе 4):
  1. допуск записи бленда 5% / 10% → порог по шуму: частично. Его замер «проклятия победителя» у fallback верен
     (0 / 0.0036 F1), но не учтён главный перекос: честная оценка самого бленда занижена (веса фолда — по 1–2 годам,
     для test — по всем), поэтому на всех трёх копиях «по CV хуже, на отложенной части лучше». Для схемы «по периодам»
     порог по SE из 2–3 фолдов почти случаен — допуск 10% остаётся;
  2. отбор топ-16 в пул бленда по всем фолдам завышает честную оценку → отбор для фолда по остальным фолдам: да;
  3. CV недооценивает модели на истории сущности: диагноз верен. Новое: в public-test **79% строк — здания,
     знакомые по train** (год 5 — 69%, год 4 — 78%), а ~¾ квадрата ошибки дают новые здания — общие веса бленда
     подбираются под них, модели с историей получают ~0. Отсюда — свои веса для знакомых и новых сущностей.
- Модели fallback с большим весом в бленде (public-мультикласс: случайный лес 0.4, LightGBM balanced 0.24) обучены
  одним сидом: сидами fallback усредняет только свой лучший кандидат, зоопарк B — только свои модели.

## 2. Что сделано

| Что | Где |
|---|---|
| `blend(..., segments=True)`: регрессия с сущностью fallback — веса Caruana отдельно для строк, где у сущности есть история (по периодам — она была в более раннем периоде; иначе — в других фолдах), и для новых сущностей; test — по тем же сегментам (`entity_rows`); честная оценка — по сегментам на чужих фолдах | `ensemble.py` |
| `blend(..., select="per_fold")`: для честной оценки фолда f сильнейшие `max_pool` отбираются по остальным фолдам | `ensemble.py` |
| `blend(..., fit="last" / "last2", bags=N)`: веса по последнему периоду(ам); среднее весов по бутстрепу строк — варианты для замеров | `ensemble.py` |
| второй бленд в `solution.improve` — только модели fallback (схема CV не «по периодам»), какой писать — решает `pick` | `solution.py` |
| `final.pool_members` (сиды моделям fallback) — функция есть, в решении не используется: на копии мультикласса хуже | `final.py` |
| лаборатория бленда: кандидаты копии считаются один раз (`lab.pkl`), стратегии сравниваются за секунды; копия «годы 1–3 → год 4» | `tools/blend_lab.py` |

## 3. Как проверить

```sh
LLM_DISABLED=1 .venv/bin/python -m pytest tests/ -q
.venv/bin/python tools/blend_lab.py copy reg_year4 --last-train 3
FALLBACK_THREADS=4 .venv/bin/python tools/blend_lab.py build reg_year5 reg_year4
.venv/bin/python tools/blend_lab.py eval reg_year5 reg_year4 cls_groups25
```

## 4. Замеры

Копии public-регрессии (`tools/blend_lab.py`): кандидаты те же, что в финальном бленде solution (fallback + зоопарк A
с сидами + зоопарк B, 41 кандидат); RMSE на отложенном годе по строкам без нового в test штата (год 4 — 98% строк,
год 5 — 83%) и по всем строкам; «CV» — честное по фолдам поздних периодов, как сравнивает `solution.pick`.

| стратегия | год 4: CV | год 4: знакомые / все | год 5: CV | год 5: знакомые / все |
|---|---|---|---|---|
| fallback (в файле без бленда) | 45.33 | 34.49 / 35.58 | 36.81 | 30.08 / 49.07 |
| бленд v6 (поздняя половина периодов) | 45.56 | 33.48 / 34.55 | 38.46 | 29.73 / 42.88 |
| + бутстреп весов (10) | 45.53 | 33.47 / 34.54 | 38.36 | 29.67 / 42.85 |
| + сегменты сущности | 45.55 | **32.21** / 33.33 | 37.34 | 29.82 / 42.93 |
| **+ сегменты + бутстреп (v7)** | 45.54 | **32.26 / 33.38** | 37.13 | **29.64 / 42.83** |
| веса по последнему году (`fit="last"`) | 45.49 | 33.75 / 34.78 | 38.91 | 29.22 / 41.25 |
| последний год + бутстреп 20 | 46.18 | 33.71 / 34.75 | 38.78 | **29.16** / 41.21 |
| сегменты + последний год + бутстреп | 45.51 | 33.62 / 34.66 | 37.26 | 29.42 / 41.37 |
| бленд только моделей fallback | 46.15 | 34.49 / 35.59 | 37.51 | 30.16 / 47.59 |

Пул сильнейших для отбора 16 → 24 (`MAX_POOL`, с сегментами и бутстрепом): год 4 32.26 → **32.19**, год 5 29.64 →
**29.54** (по всем строкам 42.83 → 41.44); 10 — хуже (33.34 / 29.95). Бутстреп 20 / 30 вместо 10 — в пределах шума.

Копия public-мультикласса (`cls_groups25`, 25% групп дублей; Macro F1 с весами классов, больше — лучше):

| | честное CV | отложенная часть |
|---|---|---|
| fallback | 0.6454 | 0.6400 |
| бленд v6 (fallback + зоопарк; с настройками v7 — то же: кандидатов 14 < 24, сегментов нет) | 0.6351 | 0.6463 |
| **бленд только моделей fallback** | **0.6375** | **0.6532** |
| то же, подбор весов классов 120 / 300 с вместо 30 | 0.6375 | 0.6532 |

Сиды моделям fallback с весом в бленде (`final.pool_members` → `final.bag`: случайный лес, LightGBM balanced, CatBoost — bag3) не взяты: бленд только fallback 0.6532 → 0.6448 (замена одиночных на bag3) / 0.6349 (добавка), полный бленд с ними — 0.6485.

Отсюда второй вариант бленда в `solution.improve` — только модели fallback (с их сидами от зоопарка B), какой писать —
решает `pick` по честному CV. **Только если схема CV не «по периодам»**: на копиях регрессии `pick` по 2–3 поздним
фолдам выбрал бы бленд только fallback (год 5: CV 36.89 против 37.32), а на отложенном годе он хуже (29.87 против
29.54; год 4 при пуле 24 — 34.34 против 32.19).

Выводы:
- сегменты + бутстреп — лучше бленда v6 на обоих годах (−1.22 и −0.09) и лучше fallback (−2.23 и −0.44): в v7;
- веса по последнему году отдают вес lag-моделям (год 5: `xgb_lag` 0.36, `xgb_log_lag` 0.35, случайный лес 0.22; в v6
  у lag-моделей 0) — предложение holdhype №3 подтверждается на годе 5 (−0.57), но на годе 4 хуже v6 (+0.25):
  нестабильно, не по умолчанию;
- отбор сильнейших по фолдам (№2 holdhype) прогноз на test не меняет, честная оценка бленда — ниже на 0.0–0.4 RMSE;
  решение о записи на обеих копиях то же (бленд пишется: допуск 10% для схемы «по периодам»);
- порог по шуму вместо допуска (№1 holdhype) на годе 5 при k = 1 отклонил бы бленды с весами по последнему году
  (выигрыш −2.10 при SE 1.88), которые на отложенном году лучше всех: для схемы «по периодам» оставлен допуск 10%.
