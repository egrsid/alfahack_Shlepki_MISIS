# feature/llm-client (P2)

## Цель
Надёжная обёртка над OpenAI-совместимым API для Qwen: ключ и адрес только из переменных окружения, повторы запросов, учёт токенов, кэш, JSON-ответы с проверкой.

## Интерфейс
- LLMClient.chat(messages, **kw) -> str
- LLMClient.chat_json(messages, schema) -> dict
- исключение LLMUnavailable: вызывающий код откатывается на эвристики

## Шаги
1. Минимальный chat() и smoke-тест
2. Повторы, таймаут, обработка ошибки "Budget has been exceeded"
3. Учёт токенов и дисковый кэш
4. chat_json с проверкой ответа
5. Тесты на моках

## Готово, когда
- работает на обеих public-задачах и не вешает процесс
- в коде нет ключей и лишних пакетов
- тесты проходят без обращения к LLM

## Риски
- Qwen вернёт невалидный JSON: проверка и повторная попытка
- общий дневной лимит 600 рублей: кэш и моки в тестах
