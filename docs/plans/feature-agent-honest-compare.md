# Ветка `feature/agent-honest-compare` — честное сравнение с fallback (P4, @egrsid; правки P1/P3 — с их согласия)

> Идея 1 из разбора «почему агент не улучшает модель»: любые находки агента должны доходить до `submission.csv`,
> если они честно лучше. Ветка от `main` (`0a31067`).

## 1. Зачем

В сабмит всегда уходил кандидат fallback, даже когда агент или AutoML что-то находили. Причины в коде сравнения:

1. **Оценка бленда fallback завышена.** Веса бленда (`fallback.blend`, Caruana) подобраны на тех же OOF, по которым
   бленд оценивается. Претенденты (`ensemble.blend`, кандидаты агента) оцениваются честно, поэтому проигрывали по
   построению. Замер на public (OOF настоящего прогона fallback, `fallback.fold_weights`):

   | задача | бленд, веса на тех же OOF | бленд, честно (веса фолда — по остальным) | завышение | лучшая одиночная |
   |---|---|---|---|---|
   | регрессия, RMSE ↓ | 40.52 | **41.09** | 0.57 (SE 0.21) | xgboost 40.81 |
   | мультикласс, Macro F1 ↑ | 0.6498 | **0.6446** | 0.005 (SE 0.004) | — |

   На регрессии завышение больше порога шума агента (0.4–0.6), а честный бленд хуже одного XGBoost.
2. **Один сид против трёх.** Итог fallback усреднён по 3 сидам (`bag_seeds`), кандидат агента — один сид:
   агент проигрывал записанному сабмиту на шуме сида, а не на качестве признаков.
3. **AutoML забирал 40 минут окна агента** и проигрывал fallback и на CV, и на отложенной части (P3: 0.578 против
   0.661; регрессия 45.0 против 41.4).

## 2. Что сделано

| Что | Где |
|---|---|
| `fold_weights` — веса бленда для каждого фолда тем же отбором на остальных фолдах; `mix_by_folds` — честный OOF; `_greedy_weights` вынесен из `blend` (поведение `blend` то же) | `fallback.py` |
| `make_candidate(..., honest_oof=)` → `meta["honest"]` (OOF, оценки по фолдам, в т.ч. с честным порогом/весами классов); `honest_view(cand)` — кандидат с честной оценкой для сравнения (test_pred и decision прежние) | `fallback.py` |
| бленд fallback и его усреднение по сидам получают `meta["honest"]` и `meta["fold_members"]`; `FallbackContext.fold_members` — для агента; `seed_params` — общий сид для bag3 fallback и агента. **Выбор внутри fallback и запись не изменились** | `fallback.py` |
| `RecipeEvaluator`: честная оценка рецепта (фолд f — смесь весами `fold_members[f]`, модели вне рецепта — их OOF из fallback), `oof` кандидата — честная смесь; `bag()` — дообучение сидов 1..`bag_seeds`−1 (те же сиды, что у bag3 fallback) и усреднение с кандидатом | `agent_eval.py` |
| агент: после исследования лучший принятый кандидат доводится до `bag_seeds` сидов (`_Research.finalize`, после окна research, с запасом `final_reserve_seconds` = 600 с до конца 3 часов; не успевает — пропуск); цикл вынесен в `_loop`; лог эталона показывает итог fallback (раньше печатал сам эталон) | `agent.py` |
| `pick` сравнивает претендентов с честной оценкой записанного (`honest_view`) с обеих сторон; в `ensemble.blend` fallback идёт с честным OOF | `solution.py` |
| AutoML выключен по умолчанию (`AUTOML_SECONDS = 0`, включение — `SOLUTION_AUTOML_SECONDS`) | `solution.py` |

## 3. Как проверить

```sh
LLM_DISABLED=1 .venv/bin/python -m pytest tests/ -q
.venv/bin/python tools/try_solution.py "Регрессия/task.md" --dry-run   # MockLLM, весь конвейер
```

Новые тесты: веса фолда подбираются без самого фолда, `honest_view`; эталон `RecipeEvaluator` на бленде равен
честной оценке fallback, а `bag()` без новых колонок воспроизводит записанный bag3 fallback (те же сиды); агент
доводит лучшего до 3 сидов, выключается/пропускается без времени; `pick` сравнивает с честной оценкой; AutoML выключен.

## 4. Замеры

**Отложенная копия регрессии** (как у P3: train — годы 1–4, test — год 5 с известными ответами, без штата, которого
нет в train), RMSE ↓, fallback этой ветки:

| кандидат | CV (веса на тех же OOF) | CV честно | отложенный год 5 |
|---|---|---|---|
| бленд fallback, bag3 (записывается) | 41.63 | 41.84 | **30.31** |
| xgboost одиночный | 42.09 | 42.09 | 30.66 |
| lightgbm_entity | 42.99 | 42.99 | 30.66 |
| честный бленд `ensemble` (fallback + все его модели) | 42.13 | 42.13 | **30.25** |

- Бленд fallback на новом годе лучше одиночных моделей — внутренний выбор fallback не меняем. Честная оценка тоже
  выбрала бы его (41.84 < 42.09); на полном train честный бленд хуже XGBoost (41.09 против 40.81) — это не
  подтвердилось на отложенном годе, т. е. в пределах шума.
- Честное сравнение не портит файл: `ensemble` не лучше честной оценки fallback больше шума — запись не изменилась бы
  (а и изменившись, на отложенном годе не хуже: 30.25).

## 5. Ограничения и что дальше

- Выбор внутри fallback (бленд или одиночная модель) — по-прежнему по оценке с весами на тех же OOF (строгое правило
  «больше шума»). Честная оценка используется только при сравнении с агентом/ensemble.
- Доводка агента до 3 сидов стоит 2 × время эталона рецепта (регрессия ~3.5 мин, мультикласс ~7–10 мин) после окна
  research; на платформе запас после окна — 30 мин.
- Следующий шаг (идея 2): быстрый скрининг гипотез одной моделью с общими сидами.
