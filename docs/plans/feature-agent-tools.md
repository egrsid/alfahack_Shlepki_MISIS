# Ветка `feature/agent-tools` — агент выбирает действия над рецептом, а не только добавляет колонки (P4, @egrsid)

> Ветка от `feature/agent-pool` (идеи 1–5). Причина: score 22.46 дал fallback, агент ничего не улучшал.

## 1. Зачем

Всё, что реально двигало score, сделано руками внутри fallback: схема CV по годам / группам дублей, признаки по
таргету сущности, исключение колонки-периода, веса классов, бленд. В режиме рецепта агенту оставалось одно действие —
добавить колонку к сильному бустингу; это самый слабый рычаг (деревья сами строят большинство взаимодействий).
Живой прогон на public-мультиклассе: 5 из 5 гипотез на скрининге ухудшили Macro F1 на ~0.0015.

## 2. Что сделано

| Что | Где |
|---|---|
| вид-действие `drop`: исходные колонки исключаются из всех моделей рецепта (`drop_columns` → колонки матриц, в т. ч. `col__freq`) | `agent_eval.py` |
| вид-действие `weights`: `dedup` (1/размер группы дублей), `recency` (поздние периоды тяжелее; нужен период-CV), `class` (power 0.5 — sqrt, 1 — balanced); веса только на обучении фолда, оценка без весов | `agent_eval.row_weights`, `fallback._fit_predict(sample_weight=)` |
| вид-действие `target_stats`: признаки по таргету для ключа из 1–3 колонок (до 2 за раз, 4 всего): регрессия/бинарная — mean/count/median, мультикласс — доли классов и count; без утечки (своя строка и валидация не участвуют, при новом периоде — только прошлые) | `fallback.target_key_features` (на `_entity_level`), `agent_eval.action_args` |
| состояние рецепта (`recipe_state`: drop / weights / target_keys) накапливается с принятыми действиями; скрининг, `bag()`, скрытый фолд и пул работают с ним; отпечаток эксперимента = код + состояние | `agent.py` (`action_state`, `_digest`, ветка действия в `_iterate`) |
| планировщик: описание инструментов и формат `"action": {...}`; кодер для действий не вызывается; ошибки действия (неизвестная колонка, неприменимая схема) попадают в память | `prompts_agent.py`, `agent.py` |
| «быстрый рецепт»: медленный член с малым весом (CatBoost 240 с при весе 0.17) не переобучается — OOF/test из fallback как есть | `RecipeEvaluator(fast=True)` |
| скрининг больших задач: подвыборка ≤ 30 тыс. строк обучения фолда (валидация целиком), один сид, если оценка одного сида > 30 с | `ScreenEvaluator` |
